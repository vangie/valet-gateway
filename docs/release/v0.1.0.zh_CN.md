# Valet Gateway v0.1.0

供 AI Passport 和 Metalio E-Ink4 Plus 共用的首个独立网关版本。
OpenClaw 和 Hermes 插件包版本仍为 **0.7.5**；共享项目版本独立于固件和插件包版本。

- 保留 `ai-passport-openclaw`／`ai-passport-hermes`、`/passport/v1`、v3 Ed25519
  签名、配对格式、长期设备凭据和数据库格式。
- 新增接受签名身份 `esp32s31 / e-ink4-plus`，继续接受 Passport 的
  `esp32c3 / ai-passport`。源码抽离不要求重新配对。
- 提供完整安装包、源码包、记录准确提交与插件版本的 `release-manifest.json`，
  以及 `SHA256SUMS.txt`。
- 现有兼容插件可继续使用。发布包不会自动替换／重启网关、授予权限或刷固件。

本机 OpenClaw 传输／relay／IMA 回归及真实 Hermes v0.23.1 运行时的 31 项隔离
回归全部通过。OpenClaw 2026.11.4 曾使用临时插件和设备身份单独互测；这不代表
所有设备、网络和提供方的完整体验已验收。阅读／按书上下文扩展尚未实现或宣称支持。

下载后运行 `shasum -a 256 -c SHA256SUMS.txt`，再按对应插件说明通过正常生命周期
安装。保留现有配置、设备授权与上一版插件以便回退。参见
[OpenClaw](../../tools/openclaw/README.zh_CN.md) 和
[Hermes](../../tools/hermes/README.zh_CN.md) 安装说明。
