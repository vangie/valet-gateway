# Valet Gateway v0.2.0

OpenClaw and Hermes adapter packages are **0.8.0**. Gateway, adapter and firmware versions are independently numbered.

- Adds opt-in current-page questions with book title, chapter, page and bounded UTF-8 page text. Book sessions and standalone sessions stay separate.
- Adds book-aware Live: the same page is included in realtime instructions and agent consultations. Existing persona and tool authority remain intact.
- Adds opt-in completed-answer speech, scoped to the authenticated device/session/run, with IMA audio, pacing and cancellation. Text remains available when the host TTS is unavailable.
- Supports plugin-local OpenAI speech using existing private credentials, independently of global host TTS. Other host speech formats can use local ffmpeg conversion.
- Preserves old Passport IDs, v3 Ed25519 proof, bootstrap/device tokens, `/passport/v1`, databases and non-opted-in behaviour. v0.1.0 and released Passport firmware pins are unchanged.

Verification: legacy OpenClaw plugin/relay/IMA tests, new context/media tests, bounded synthesis and cancellation tests, package allowlists and checksum receipts. Real Hermes runtime isolation tests and provider probes use temporary services; they do not upgrade production gateways. Real OpenAI speech was generated on both Kyan and Elise using existing private credentials; book Live reached the realtime provider and accepted IMA audio on Elise. E-Ink4 physical playback/microphone/4G acceptance remains outstanding. Host model/credential availability and remote network stability remain deployment-specific.

Install explicitly from this release after checking `SHA256SUMS.txt` and `release-manifest.json`. Preserve old code/config for rollback. This release does not automatically deploy, restart a gateway or flash a device. Reloading an upgraded plugin can interrupt existing calls, so choose a maintenance window.
