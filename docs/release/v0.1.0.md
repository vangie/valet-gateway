# Valet Gateway v0.1.0

First independent gateway release for AI Passport and Metalio E-Ink4 Plus.
The OpenClaw and Hermes adapter package versions remain **0.7.5**; the shared
project version is independent from firmware and adapter package versions.

- Preserve `ai-passport-openclaw` / `ai-passport-hermes`, `/passport/v1`, protocol-v3
  Ed25519 proofs, pairing formats, persisted tokens and existing database formats.
- Accept the additional signed `esp32s31 / e-ink4-plus` identity while retaining
  Passport's `esp32c3 / ai-passport`. No re-pairing is needed for source extraction.
- Include complete installable packages, a source archive, `release-manifest.json`
  with the exact commit and adapter versions, and `SHA256SUMS.txt`.
- Existing compatible installations can stay in place. Package publication does
  not update/restart gateways, grant permissions or flash firmware automatically.

Local OpenClaw transport/relay/IMA tests and all 31 Hermes tests under the real
Hermes v0.23.1 runtime passed in isolation. OpenClaw 2026.11.4 gateway integration
was checked separately using a temporary adapter and device identity; this is
not a claim of end-to-end acceptance for every device/network/provider.
Reading/book context extensions are not implemented or advertised.

Verify the downloaded files with `shasum -a 256 -c SHA256SUMS.txt`, then install
from the relevant adapter directory using its documented normal lifecycle.
Preserve existing configuration and device grants. Keep the previous reviewed
adapter for rollback. See the [OpenClaw](../../tools/openclaw/README.md) and
[Hermes](../../tools/hermes/README.md) installation guides.
