# Valet Gateway v0.2.0

共享项目版本 **0.2.0**，OpenClaw／Hermes 插件包版本 **0.8.0**，与固件版本独立。

- 当前页提问：带书名、章节、页码和有界正文，书本会话与随口问隔离。
- 带书 Live：实时模型与工具咨询都收到当前页，保留原人设与工具授权。
- 问答语音播报：仅合成当前设备／会话已完成的答案，IMA 分帧、限速、取消与撤销检查；播报失败保留文字。
- 可在插件内复用现有 OpenAI 私有凭据，不改宿主全局 TTS。宿主其他音频格式可由本地 ffmpeg 转换。
- 保留旧 Passport 插件 ID、签名、配对／长期凭据、数据库及未声明新能力时的原行为；v0.1.0 和已发布 Passport 的依赖不变。

已跑旧协议及新上下文／媒体测试、打包与校验；Elise 上使用隔离服务验证真实 Hermes 和带书实时提供方，Kyan／Elise 均以已有私有凭据完成真实 OpenAI 语音合成。E-Ink4 的物理麦克风、扬声器及 4G 仍待真机验收。模型／凭据和网络是否可用取决于实际部署。

下载后核对 SHA256SUMS.txt 和 release-manifest.json，保留旧插件和配置以便回退。不会自动替换／重启生产网关或刷机；正常重载插件可能打断通话，应选维护时段。
